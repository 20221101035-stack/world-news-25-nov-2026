A program that writes a one-image summary of the world's news of Wednesday 25 November 2026 to /output/entry.png: a newspaper front page ("THE WORLD TODAY") leading on two oil tankers hit by mines in the Strait of Hormuz, with Pakistan's first astronaut reaching orbit aboard Shenzhou-24, Huawei's conviction on 10 of 12 counts, Asia's chip-led market rout, the Australia–Solomon Islands base pact, the COP31 talks ending with no deal, and an in-brief column. All text is composed with PIL so it stays crisp; the lead photograph is AI-generated.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=out python3 main.py
```
